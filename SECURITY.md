# Security policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public GitHub issue or include exploit details in a public discussion.

Use GitHub's **Report a vulnerability** option for this repository if private vulnerability reporting is enabled. If it is unavailable, contact the repository maintainers privately through GitHub and ask for a secure reporting channel. Include a concise description, affected component/version, impact, and safe reproduction details. Do not attach real user or health data.

We will acknowledge reports as soon as reasonably possible and coordinate a fix and disclosure with the reporter. Please give maintainers a reasonable opportunity to investigate and release a fix before public disclosure.

## Scope and sensitive data

The mobile app, Flask backend, and repository deployment configuration are in scope. Third-party providers (including Twilio, OpenRouter, Render, and Firebase) have their own reporting processes.

Never submit secrets, credentials, or personally identifiable or health information in a report. Revoke and rotate any credential that may have been exposed.
